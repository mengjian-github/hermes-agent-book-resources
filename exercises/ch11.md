# 第11章：生产边界

对应书稿 11.9，共 5 题。题干为摘要；按书中原顺序编号。核查日期：2026-09-18。共同前提与验证记录见 [练习说明](README.md)。

## 11.9-1 Docker 后端

前提：专用环境，Docker daemon 可用。

参考步骤：按[部署 README](../examples/ch11-production-deploy/README.md)配置 backend，运行 doctor 后做真实容器终端测试。

验收：有后端实际路径/读取结果，且记录模型和版本。

排查与边界：doctor 不能替代真实执行；不要混用容器路径和宿主路径。

## 11.9-2 输入只读、输出可取

前提：创建仅含合成内容的宿主 input/output 目录。

参考步骤：合并 production-profile.yaml 的两个 docker_volumes；读 /data 成功，写 /data 失败，写 /output 成功，宿主同名文件可见并能由 Gateway 发送。

验收：四项均有证据，输入文件前后哈希不变。

排查与边界：不要挂载宿主根目录或 Docker socket；只读 input 不意味着其他宿主卷也只读。

## 11.9-3 检查点及 diff

前提：默认关闭，先开启；只在练习项目测试。

参考步骤：`hermes -p book-lab chat --checkpoints`，让工具修改一个测试值，`/rollback` 查看实际编号，再 `/rollback diff 1`，必要时恢复单个测试文件。

验收：能看见 Agent 修改对应的 diff；记录编号和文件，不覆盖手工改动。

排查与边界：仅输入无编号的 diff 不足；检查点不是全部数据的备份。

## 11.9-4 .env 权限

前提：针对真实 Profile 的 .env，不是仓库模板。

参考步骤：Linux 查看所有者及模式，目标为服务账户拥有且600；Windows 用 icacls 看实际 ACL，限制无关账户读取。config.yaml、Git、日志中检查无密钥值。

验收：记录权限状态和整改后证据，仅展示变量名。

排查与边界：不要照抄未知用户名的 ACL 修改命令；备份也须保护。

## 11.9-5 部署清单

前提：使用[可填写清单](../examples/ch11-production-deploy/deployment-checklist.md)。

参考步骤：逐项填写负责人、日期、实际证据、结果、回退方式；至少覆盖版本、凭据、两卷、消息、Cron、重启和备份恢复演练。

验收：未做的标待验收；完整恢复应在独立测试目录验证，不直接覆盖运行实例。

排查与边界：有备份文件不代表能恢复，程序回退不等于数据库格式可回退。

依据：[本章官方参考](https://hermes-agent.nousresearch.com/docs/user-guide/checkpoints-and-rollback)。具体命令以已安装版本帮助为准；题干需修改处另见 [书稿勘误](../docs/book-errata-2026-09-18.md)。
