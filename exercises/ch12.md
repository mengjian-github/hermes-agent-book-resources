## 12.10-1 接入低风险查询

前提：使用[真实 MCP 示例](../examples/ch12-internal-docs-mcp/README.md)，Python依赖已装。

参考步骤：先运行 unittest 的 stdio 握手与调用测试；再用 render_config.py 生成解释器/服务绝对路径，合并到目标 Profile 并新建会话。

验收：Hermes 实际发现 search_docs/read_doc；普通 CLI 搜索成功不算 MCP 接入成功。

排查与边界：server.py 直接运行等待协议是正常行为，stdout 不能混入日志。

## 12.10-2 连接与最小权限

前提：本地 stdio 无远程 Token，不照抄占位 HTTPS 地址。

参考步骤：检查 command/args、tools.include 的两项、tools.prompts=false、tools.resources=false、sampling.enabled=false；同名配置合并，保留其他服务。

验收：工具发现只包含预期能力；服务器自身拒绝越界，未提供写入工具。

排查与边界：resources/prompts 在 tools 下；只读注解不是操作系统沙箱。
