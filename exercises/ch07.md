# 第7章：记忆与会话

对应书稿 7.8，共 5 题。题干为摘要；按书中原顺序编号。核查日期：2026-09-18。共同前提与验证记录见 [练习说明](README.md)。

## 7.8-1 清理过时记忆

前提：确认目标 Profile 的 memories 路径，备份已有文件。

参考步骤：检查 USER.md/MEMORY.md 中失效偏好、旧项目路径、临时待办和敏感内容；逐条标保留/更新/移出/删除理由。文件不存在则记录首次状态，不编造旧条目。

验收：仅改已确认失效的内容，保存前后差异。

排查与边界：项目里的 memory/ 是样本，不自动生效；不要一键覆盖整个个人记忆。

## 7.8-2 区分偏好与项目事实

前提：使用[记忆示例](../examples/ch07-personal-assistant-memory/README.md)。

参考步骤：偏好例：中文、结论在前，放 USER；事实例：练习项目使用 Python，测试由 unittest 运行，放 MEMORY。先确认事实；新会话问下一步，不显式要求读文件。

验收：新会话能运用相应内容，且不把临时会话测试码写成长期记忆。

排查与边界：长期记忆必须最小化，不放 Token、密码或未经证实的推断。

## 7.8-3 最近五会话与命名

前提：目标 Profile 有可用历史。

参考步骤：`hermes -p book-lab sessions list`，按时间查看最近五条，不足五条如实记数；核对 ID 后 `hermes -p book-lab sessions rename <ID> "项目回顾"`，再 list。

验收：指定会话标题改变，其他会话不变。

排查与边界：不得拿标题猜 ID 或为了凑数量伪造历史。

## 7.8-4 项目 AGENTS.md

前提：放在实际练习项目根，先阅读现有规则。

参考步骤：写明架构路径、测试命令、风格约定、禁止提交密钥/修改范围；可参考[项目样本](../examples/ch07-personal-assistant-memory/project/AGENTS.md)。从项目根启动会话，要求先复述生效规则后做一个无副作用检查。

验收：规则与真实结构一致，测试命令能执行。

排查与边界：不要用样本覆盖已有规则，也不要把 AGENTS.md 当操作系统权限控制。

## 7.8-5 外部记忆需求

前提：先区分轻量偏好与大量跨项目知识检索。

参考步骤：运行 `hermes -p book-lab memory status`。示范判断：只有表达偏好和少量事实，内置记忆足够；需共享知识检索再评估外部提供商的索引、隐私、费用与迁移。

验收：无需外部服务也可通过；记录状态与选择理由。

排查与边界：未配置提供商不是本题自动失败，不为做题上传私有资料。
