# 结构化研究报告参考格式

## 一句话定位

Hermes Agent 适合希望把 AI 接入终端、项目文件、工具系统、Skills、记忆和自动化任务的开发者或团队。

## 安装方式

- 优先参考官方安装说明；
- 安装后运行基础诊断命令；
- Windows 用户应确认 WSL2、路径和权限边界。

## 核心能力

- CLI/TUI 交互；
- Toolsets 控制工具边界；
- Skills 沉淀可复用流程；
- Memory 和 Context Files 保存长期偏好与项目规则；
- Cron 和 Gateway 支持自动化与消息投递。

## 风险和边界

- 不应直接接入高权限生产凭证；
- 动态工具、MCP 和插件需要额外权限审查；
- 命令、字段和环境变量可能随版本变化。

## 下一步验证

1. 在本地测试安装和 `hermes doctor`；
2. 创建只读任务验证文件读取；
3. 运行一个低风险 Cron；
4. 记录配置差异并更新项目 AGENTS.md。
