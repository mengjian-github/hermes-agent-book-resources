# 第10章：消息入口

对应书稿 10.9，共 6 题。题干为摘要；按书中原顺序编号。核查日期：2026-09-18。共同前提与验证记录见 [练习说明](README.md)。

## 10.9-1 创建 Bot 并接入

前提：使用个人测试 Bot，不复用生产 Token。

参考步骤：按[Telegram 完整流程](../examples/ch10-telegram-assistant/README.md)在 BotFather 创建，再 `hermes -p book-lab gateway setup`；启动目标 Gateway，进行允许/拒绝用户测试。

验收：记录 Bot 名、Profile、允许与拒绝结果，日志不含 Token。

排查与边界：变量应为 TELEGRAM_ALLOWED_USERS；不要让多个 polling Gateway 共用 Token。

## 10.9-2 Home Channel 日报

前提：先完成第8章本地日报验证。

参考步骤：目标聊天 `/sethome`；将第8章创建命令的 --deliver local 改成 --deliver telegram，使用新测试名，run 后等待附件/文字真正到达。

验收：任务 ID、输出时间、聊天接收时间能对应；每天09:00时区明确。

排查与边界：正确变量是 TELEGRAM_HOME_CHANNEL；DM topic 模式还需确认目标线程，不能默认根聊天能继续会话。

## 10.9-3 提及与唤醒词

前提：仅在测试群验证，并保证消息已被 Telegram 投递。

参考步骤：用 README 中 telegram.require_mention 和 mention_patterns 片段；依次测试普通消息不响应、@bot 响应、约定前缀响应，重启配置后重复。

验收：三项都有实际记录，保留用户白名单限制。

排查与边界：群隐私模式与 Hermes 触发规则是两层，不要把收不到消息误判为正则错误。

## 10.9-4 语音到文本

前提：配置 STT 提供商及必要本地依赖或密钥。

参考步骤：发送“明天下午三点整理会议纪要，请只复述不创建提醒”；核对转写中时间、事项与文本回复。失败查看 STT 开关/提供商/下载日志。

验收：语义正确且没有擅自建提醒；不要求 TTS 回语音。

排查与边界：未启用 STT 时仅收到音频路径不算转写通过。

## 10.9-5 固定 Topic 或 /topic

前提：选择一种模式，前提见 README，不混用配置层级。

参考步骤：固定模式配置 platforms.telegram.extra.dm_topics 并启用聊天 Topics；自建模式在 BotFather 开 Threaded Mode/用户创建权限后根私聊 /topic。创建A/B，分别写仅会话内测试内容并检查隔离。

验收：会话 ID 不同，B 不继承 A 的聊天历史；说明 Profile 记忆仍可能共享。

排查与边界：Topic 不是文件权限或所有长期记忆的隔离边界。

## 10.9-6 PDF MEDIA 附件

前提：安装 reportlab，Gateway 能读宿主输出路径。

参考步骤：运行 generate_pdf.py output/telegram-test.pdf，打开本地文件核对，再让 Telegram 会话返回脚本生成的绝对 MEDIA 路径。Docker 用挂载后的宿主路径。

验收：实际收到可打开的 PDF，正文含测试标题；记录大小和路径。

排查与边界：终端打印 MEDIA 不会自行向 Telegram 发消息，必须经过 Gateway 响应处理。

依据：[本章官方参考](https://hermes-agent.nousresearch.com/docs/user-guide/messaging/telegram)。具体命令以已安装版本帮助为准；题干需修改处另见 [书稿勘误](../docs/book-errata-2026-09-18.md)。
