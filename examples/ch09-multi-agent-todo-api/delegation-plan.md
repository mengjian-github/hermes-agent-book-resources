# 多 Agent 协作拆分

## 研究子代理

- 目标：调研 REST API 常见结构、错误处理和测试建议；
- 工具集：`web`；
- 写入权限：不写文件；
- 交付：接口设计建议和测试清单。

## 实现子代理

- 目标：实现待办事项数据结构和 CRUD 服务；
- 工具集：`file`、`terminal`；
- 写入范围：`src/todo_app/`；
- 交付：可导入的服务模块。

## 测试子代理

- 目标：为新增服务补齐单元测试；
- 工具集：`file`、`terminal`；
- 写入范围：`tests/`；
- 交付：覆盖创建、列表、完成、删除和错误输入的测试。

## 合并代理

- 检查三个子代理输出是否冲突；
- 运行最小测试命令；
- 记录未完成风险。
