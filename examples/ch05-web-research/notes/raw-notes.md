# 原始资料笔记示例

## Official documentation

- Hermes Agent 是面向 CLI/TUI、工具调用、Skills、记忆和自动化任务的 Agent 工作系统。
- 配置以 Hermes Home 为中心，常见文件包括 `config.yaml`、`.env`、`SOUL.md`、`skills/`、`cron/`、`sessions/`。
- Toolsets 是工具可用范围的基本单位，包括 Core、Composite、Platform 和 Dynamic Toolsets。

## GitHub repository

- 安装方式通常通过官方脚本或项目说明完成。
- 需要根据当前版本复核命令和环境变量。
