# 练习使用说明

入口：[57题答案索引](answers.md)。题号按“书稿练习节-原题序号”组织，不另加题目替代原题。

## 共同前提

- 从仓库根目录执行相对路径命令；先完成根 README 的依赖安装和离线验证。
- Hermes 操作使用专用 book-lab Profile，模型由自己的向导配置；用 `hermes profile show book-lab` 确认实际目录。示例中的 `<ID>` 和 `/absolute/...` 必须替换。
- Shell命令在终端输入，`/tools` 等斜杠命令在 Hermes 会话输入。Windows 原生环境能跑本仓库 Python 测试；Hermes/Linux服务部分按官方安装平台要求操作，WSL中的路径使用其Linux路径。
- 操作题不是已经替读者执行的记录。真实模型、Telegram、Docker、Cron、Hub 和 Hermes MCP集成均需自己的环境验收。
- 文件写入、发消息和部署只在题目所授权的测试范围内；先备份已有配置、密钥不进Git、不覆盖个人记忆。
