# 第5章：工具与验证

对应书稿 5.8，共 5 题。题干为摘要；按书中原顺序编号。核查日期：2026-09-18。共同前提与验证记录见 [练习说明](README.md)。

## 5.8-1 safe 调研

前提：可用网页读取依赖；使用公开资料。

参考步骤：`hermes -p book-lab chat --toolsets safe`，先 `/tools list`；要求比较两个官方资料页，给主张与来源。核对未暴露写文件、终端、代码执行工具。

验收：报告可在聊天中呈现，来源支持结论；不为了保存文件临时突破 safe 能力范围。

排查与边界：工具集名称不是自然语言安全保证，需核对实际工具清单。

## 5.8-2 定位后阅读

前提：使用 ch03 认证代码。

参考步骤：让 search_files 在示例目录查找 `change_password`，再 read_file 阅读命中函数与会话验证上下文；记录具体符号名、位置及调用关系。

验收：先定位后阅读，发现密码修改与会话失效之间的关系。

排查与边界：若当前代码符号不同，先按 password 搜索，不编造行号。

## 5.8-3 最小 patch 与 diff

前提：在临时练习分支或项目副本中创建练习配置，先确认 git status。

参考步骤：让 Agent 仅把测试配置的 retries 从 1 改为 2，要求用 patch；再运行 `git diff -- <实际文件>`，检查只有一项修改，按项目命令验证。

验收：交付最小 diff 和验证结果；想恢复时用反向小补丁，只撤销自己的行。

排查与边界：不要在脏工作区使用 reset --hard 或整体覆盖用户文件。

## 5.8-4 网页提取与浏览器

前提：选可公开访问且不要求登录的网页。

参考步骤：先 web_extract，检查目标字段是否存在；缺少动态渲染内容时再 browser_snapshot，记录提取缺口、浏览器补充证据与 URL。若第一步信息完整，说明无需第二步。

验收：结论基于真实页面，明确动态内容、访问失败和未确认信息。

排查与边界：工具缺依赖或遇到权限页面时如实报告，不把失败内容当页面事实。

## 5.8-5 本地服务器生命周期

前提：终端中只对示例目录开放 localhost。

参考步骤：用 `python -m http.server 8765 --bind 127.0.0.1 --directory examples/ch05-web-research` 启动。让 Agent 以 terminal 的后台/进程管理能力保留进程 ID，访问本机 URL，观察请求日志；最后终止该确切进程，再访问应失败。

验收：记录启动、PID、请求状态、日志、停止后端口状态。

排查与边界：端口占用时选新端口，不 kill 未确认进程；不能把整个用户目录暴露为 HTTP 根目录。
