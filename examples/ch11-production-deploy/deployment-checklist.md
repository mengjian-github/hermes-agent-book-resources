# 部署验收记录

每项填写：负责人｜日期｜实际证据｜通过/失败/待验收｜回退方式。

- 版本与依赖：Hermes 版本/commit、Python、Docker、模型可用性。
- 账户与密钥：非 root、.env ACL、日志脱敏、备份加密或访问控制。
- 后端：真实容器执行证据；输入卷写入失败、输出卷写入成功。
- 工具：实际暴露清单与需求匹配；提示词不充当权限边界。
- 消息：允许/拒绝用户测试、宿主 MEDIA 附件可读、没有重复 Gateway。
- 调度：时区、next run、手动触发的真实结果、测试任务清理。
- 恢复：显式启用检查点、diff 预览、完整备份恢复演练。
- 运维：日志位置、磁盘与失败告警、重启验证、升级回退基线。
